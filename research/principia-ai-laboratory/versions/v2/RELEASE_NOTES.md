# Principia AI Laboratory — 1.0.0

This release runs reproducible, CPU-only experiments to test operational versions of the proposed Newtonian AI corollaries. It includes local dashboard, 12 falsifiable comparisons, theorem-bound worlds, four small learning systems, controlled interventions, optional external binary CSV datasets, optional local Ollama tests, tests and machine-readable reports.

## Demonstration outcome

An included **standard preset, seed 42**, run has 300 architecture/condition/seed observations. Eleven registered comparisons were *consistent within the synthetic conditions*, and weak-to-strong teacher transfer (H10) was **inconclusive**. The cross-condition forecaster achieved an average absolute prediction error of **0.2340** (training-mean baseline **0.2639**); enforcing analytically known Bayes ceilings reduced this error to **0.1950**. Its unconstrained forecasts violated those theoretical ceilings in **54 of 180** held-out predictions — a real failure of the candidate forecasting model, transparently retained. These are not independently replicated or universal results.

## Interpretation

The exact information-theoretic impossibility statement can be proved under its assumptions. The learning, scaling, generalisation and correction claims need testing in additional independently selected worlds and architectures. This release makes those falsification tests executable but does not claim to have proved a universal AI law.
